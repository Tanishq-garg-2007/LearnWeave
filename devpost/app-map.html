LearnWeave AI — Interactive Code Tour & Architecture

A visual technical map tracing the student journey from learning target to local neural voice synthesis and adaptive curriculum revision.

System Overview

LearnWeave AI is an agentic personalized learning platform that structures education into 2-week active sprint roadmaps, retrieves knowledge using Hybrid RAG (pgvector + FTS with Reciprocal Rank Fusion), narrates lessons with sub-60ms local neural TTS (Kokoro-82M ONNX), and evaluates mastery through a resilient 6-step persistent state machine.

Architecture Route: Tracing One Complete Action

Follow the path of a student initiating a lesson and receiving voice audio:

Stop 1: State Machine Initialization & Resumption

File: backend/app/services/learning_cycle_engine.py

Symbol: LearningCycleEngine.start_cycle(lesson_id, user_id)

Creates or restores a persistent row in PostgreSQL table cycle_runs with state lesson_gen. If the client disconnects, resume_cycle() restores the state without re-generating LLM content.

Stop 2: Hybrid RRF Knowledge Retrieval

File: backend/app/services/retrieval_service.py

Symbol: RetrievalService.retrieve_relevant_chunks(query, user_id)

Calculates 384-d dense embeddings via local ONNX model and executes Reciprocal Rank Fusion ($k=60$) combining pgvector cosine distance and PostgreSQL tsvector keyword rank.

Stop 3: Local Neural Voice Synthesis (Kokoro-82M)

File: backend/app/services/voice_service.py

Symbol: VoiceService.synthesize_speech(text)

Passes lesson text to Kokoro-82M ONNX model. Synthesizes pristine 24kHz mono 16-bit PCM WAV audio in ~55ms without third-party network API calls.

"To Change This, Start Here"

To adjust the 2-week active sprint duration or pacing constraints

Navigate to backend/app/agents/roadmap_agent.py. Look for the constraint prompt and the sanitize_roadmap() method which limits detailed lessons to Weeks 1 and 2 and sets is_planned_later = True for subsequent weeks.

To customize quiz grading rubrics or passing thresholds

Navigate to backend/app/agents/evaluation_agent.py. The passing score threshold is currently set to 70.0. Modifying this threshold changes when AdaptiveAgent inserts a remediation lesson.

To change the local neural voice or speech rate

Navigate to backend/app/services/voice_service.py. Adjust the Kokoro-82M ONNX voice style tokens or audio sampling configuration.

To alter the UI theme or learning cycle modal layout

Navigate to frontend/src/components/LearningCycleModal.tsx for the 6-step cycle UI, or frontend/src/components/RoadmapView.tsx for the sprint visualizer.

A Practice to Reuse: State Machine Decoupling with Deterministic Guards

Many AI applications rely on unbounded prompt loops (having LLMs call other LLMs repeatedly), which leads to compounding latency, high costs, and fragile failures. LearnWeave demonstrates a robust alternative:

  • Persistent Finite State Machines: Store state explicitly in a database (cycle_runs) so user sessions are resilient to disconnects and page refreshes.
  • In-Memory Deterministic Sanitizers: Instead of asking an LLM to re-generate an entire payload when schema constraints are violated, use fast, zero-cost deterministic Python validators to sanitize and enforce business invariants.
  • Local Edge Acceleration: Use lightweight ONNX models (Kokoro-82M for audio, all-MiniLM-L6-v2 for vectors) to deliver instantaneous response times (55ms) for latency-critical tasks while keeping cloud LLMs reserved for high-reasoning tasks.

How to Run Locally

# 1. Start database container
docker compose up -d

# 2. Run backend migrations & start server
alembic upgrade head
uvicorn backend.app.main:app --host 0.0.0.0 --port 8000

# 3. Start frontend interface
cd frontend && npm install && npm run dev
